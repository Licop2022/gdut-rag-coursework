# 中文 RAG 课程作业交付

选题 B：基础 RAG 与 Cross-Encoder Rerank 对比。

本项目实现真实中文神经网络向量检索、文本对重排序和本地语言模型生成，不需要 API 密钥。知识库是自编的 20 篇 RAG 学习资料，测试集为 12 道题，其中 10 道有资料依据、2 道资料外问题。相关结果仅代表这套教学数据。

## 先打开什么

- `课程汇报_重制版.pptx`：当前课堂汇报版，10 页主讲、2 页备答，含逐页演讲备注与 LaTeX 矢量公式。原 `课程汇报.pptx` 为旧版。
- `RAG课程作业.ipynb`：理论、代码、结果和可修改问题的现场 Demo。
- `实验报告.md`：方法、实际结果、案例和局限。
- `实验结果预览.html`：直接用浏览器打开即可查看保存的结果，不能冒充现场推理。
- `四人讲稿_重制版.md`：与新 PPT 页序一致的四人讲稿、交接和演示步骤。
- `公式/公式源码.tex`：可继续修改的 LaTeX 源码，配套 SVG 公式。
- `results/raw_results.json`、`results/逐题结果.csv`：完整原始输出与逐题指标。

## 本机运行

当前工作区的独立 Python 环境位于本文件夹上一层的 `.runtime`，模型在本文件夹的 `models` 中。双击 `启动现场问答.cmd` 可加载模型并连续提问，首次启动需等待模型加载。输入 `q` 退出。

双击 `打开Notebook.cmd` 可打开 Notebook。若浏览器没有自动打开，使用终端打印的本地地址。Notebook 中修改“现场问答”单元格的 `question` 后运行即可。请提前运行模型加载单元格，台上不下载模型或重建环境。

## 换一台电脑

建议使用 Windows 64 位 Python 3.11。完整复制本文件夹，包括 `models`。压缩的轻量提交包不包含模型权重与 Python 环境，拿到轻量包需先安装依赖并下载模型。

在本文件夹打开终端：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cpu --extra-index-url https://pypi.org/simple
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe download_models.py
.\.venv\Scripts\python.exe rag_engine.py
```

模型已完整复制时跳过下载。模型共约 1.6GB，安装环境还需要额外空间。本机采用 CPU 运行；具体加载和推理时间见实验报告。程序不依赖 CC Switch，也不读取 Codex 的配置或认证信息。

轻量提交包保留 `models/manifest.json`，下载器会优先按其中固定的文件版本与 SHA256 恢复模型，避免仓库后续更新造成版本漂移。`requirements-lock.txt` 记录本次环境的完整依赖版本。

## 重新运行实验

```powershell
python run_experiment.py --output results_rerun
python -m unittest test_core.py
```

在已激活的项目环境中执行，或把 `python` 替换为项目环境中的解释器路径。为保护已交付结果，重新实验使用新的输出目录。`run_experiment.py` 默认 `results`，如需保留原结果必须显式使用 `--output`。

原始生成结果逐题保存，实验完成后才写汇总。两组复用同一召回候选，最终上下文均为 3 个片段；基础组按向量分数选取，实验组按 Cross-Encoder 分数选取。生成采用相同模型、提示词和贪心解码。初次模型加载与建库不计入逐题查询耗时。

## 代码与目录

| 文件或目录 | 作用 |
|---|---|
| `rag_engine.py` | 切分、BGE 编码、精确向量检索、Cross-Encoder 精排、Qwen 生成 |
| `run_experiment.py` | 固定测试集与实际计时、检索指标、结果导出 |
| `test_core.py` | 切分覆盖、边界检查、索引缓存失效检查 |
| `build_data.py` | 重建自编教学资料与固定测试题 |
| `download_models.py` | 下载公开模型、按仓库文件清单核对 SHA256 |
| `data/corpus` | 20 篇原始知识库资料 |
| `data/questions.json` | 固定测试问题、参考文档与答案要点 |
| `models` | 本地模型、模型卡、许可和校验清单 |
| `cache` | 向量缓存、片段元数据，语料或参数改变后自动换用新缓存 |
| `results` | 原始回答、候选排序、参数、计时与汇总 |

向量存储使用 NumPy 矩阵与 JSON 元数据，做完整精确扫描。这是便于讲解的小规模实现，没有使用 Chroma 或 Milvus，不能声称已部署企业级数据库。相关差异在报告理论部分说明。
