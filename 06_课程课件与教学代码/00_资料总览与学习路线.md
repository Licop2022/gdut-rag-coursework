### Transformer 与 Transformers 要区分

- **Transformer** 是模型架构。先读 `4.0 自然语言处理之Transformer.pdf`，再对照 `AnnotatedTransformer.ipynb` 阅读模块实现。
- **Transformers** 是资料使用的预训练模型工具库。按“库介绍 → 任务介绍 → 安装 → 快速上手 → pipeline”阅读。
- `2f4a05.01-.ipynb` 是库与支持任务的概览；`2f4a05.02-.ipynb` 是音频、视觉、NLP、多模态任务介绍，原来缺少 `.ipynb` 扩展名。
- 安装笔记本包含终端命令、示例输出和不同操作系统的写法，应按段落阅读，不能把所有代码格当成同一种 Python 程序连续执行。

## 建议学习顺序

这是根据现有资料安排的建议，不代表教师规定的进度或考核范围。

1. **打好 Python 基础**：读第一讲 PPTX 和 Python PDF，复现类与对象、数组操作、表格读取和简单绘图。
2. **理解训练闭环**：读 3.01—3.03，重点弄清张量、梯度、Dataset 和 DataLoader。
3. **完成一个小模型**：结合 3.04—3.07 阅读第5讲 LeNet 人民币二分类代码，记录数据形状、损失与验证指标。
4. **学会检查与保存模型**：读 3.08—3.09，理解正则化、验证、保存、续训和设备管理。
5. **理解注意力结构**：读 Transformer PDF，再分模块阅读 AnnotatedTransformer，先不用追求全部训练示例跑通。
6. **先调用模型，再做微调**：先看快速上手和 pipeline，再进入文本分类、NER、BitFit、LoRA，最后看量化与 QLoRA。
7. **搭建 RAG 流程**：先读文档切分、Embedding、Chroma、RAG_Bot，再读 Rerank、表格处理和 Milvus。

时间有限时，优先把“人民币二分类”和“一个文本分类 pipeline”理解透，再阅读 RAG 基础流程。
