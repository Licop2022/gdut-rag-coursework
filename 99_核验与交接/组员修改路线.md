# 组员修改路线

| 想改什么 | 去哪里 | 需要同步 |
|---|---|---|
| 姓名、组号、文字、布局 | 01_汇报材料/课程汇报_重制版.pptx | 四人讲稿；如使用 JS 重建则同步构建脚本 |
| 发言与交接 | 01_汇报材料/四人讲稿_重制版.md | PPT 演讲备注、现场切屏页序 |
| 公式 | 01_汇报材料/公式/公式源码.tex | 构建脚本中的 LATEX 字典；生成 SVG 并替换对应公式 |
| 理论解释、结论、参考资料 | 02_书面报告 | PPT、讲稿、Notebook 的同类表述 |
| 知识库 | 03_可运行项目/data/corpus | 重新建库与实验，记录语料版本 |
| 固定题集与标注 | 03_可运行项目/data/questions.json | 新结果目录、报告与图表；参考答案不得进入推理 |
| 检索或生成参数 | 03_可运行项目/rag_engine.py 的 CONFIG | 新实验、参数说明和报告 |
| 复核回答 | 03_可运行项目/results/answer_review.json | 保留原初评，另存复核版本并写清复核人、日期、标准 |

当前四人建议：甲统筹与问题，乙切分与检索，丙重排与现场演示，丁实验与评价。真实分工由组员确认。

建议每次另存 PPT 为含日期或版本号的文件，指定一人合并。当前 JS 是程序生成版本的来源；手工 PPT 修改不会自动回写到 JS。

复核优先事项：全组通读讲稿；核实助手初评；用真实姓名替换占位；若教师要求必须使用原课件思考题，补充原课件后替换自主讨论；全组排练控制在 5 分钟内。
